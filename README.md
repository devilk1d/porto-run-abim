## About This Repo

Long story short, this is my **second** personal portfolio site. I actually built one back when I first started learning to code and yeah, it was total trash (okay, maybe this one kinda is too hehe). After spending maybe over a year (?) trying to gather the motivation, I finally got around to building this thing. Nothing overcomplicated here. Just a place to put my web, mobile, and ML projects together. Check it out live at **[abiem.codes](https://abiem.codes)** — if you're reviewing my work or looking to team up on something cool, you're in the right spot.

## Run Locally

Want to spin it up on your machine?

```bash
npm install
cp env.example .env.local
npm run dev
```

Open `http://localhost:3000` in your browser and you're good to go.
